# دوره آموزش جامع و فشرده طراحی سیستم (System Design in a Hurry)
### نسخه فارسی راست‌چین (RTL) به همراه اصطلاحات تخصصی انگلیسی و فونت وزیرمتن (Vazirmatn)

این مجموعه شامل **۷۰ فصل تخصصی** دوره معروف **Hello Interview - System Design in a Hurry** است که به فارسی روان ترجمه شده و ساختار آن برای میزبانی آسان و پرسرعت روی **GitHub Pages** بهینه‌سازی شده است.

---

## ویژگی‌های نسخه جدید:
1. **ترجمه روان و مفهومی:** ترجمه دقیق مباحث مهندسی نرم‌افزار و معماری سیستم به فارسی سلیس با گرامر صحیح.
2. **حفظ اصطلاحات تخصصی انگلیسی:** اصطلاحات مهم (نظیر Consistent Hashing, Rate Limiter, Load Balancer, CAP Theorem, Sharding و...) به انگلیسی حفظ شده و در پرانتز معادل فارسی دقیق آن‌ها آورده شده است.
3. **طراحی راست‌چین (RTL) و فونت وزیرمتن:** پشتیبانی کامل از چینش راست به چپ و فونت استاندارد Vazirmatn برای خوانایی فوق‌العاده.
4. **فایل‌های استاتیک محلی (`assets/`):** کلیه وزن‌های فونت Vazirmatn به صورت محلی در پوشه `assets/fonts/` قرار گرفته تا سایت به هیچ CDN خارجی وابسته نبوده و کاملاً آفلاین هم کار کند.
5. **ناوبری هوشمند:** هر صفحه دارای نوار ابزار بالا و پایین است که رفتن به فصل بعدی، فصل قبلی و فهرست فصول (`index.html`) را فراهم می‌کند.
6. **صفحه اصلی جامع (`index.html`):** داشبورد دسته‌بندی‌شده به همراه قابلیت جستجوی آنی در فصول.
7. **بهینه‌سازی برای GitHub Pages:** حذف کدهای باینری سنگین ویدیو از داخل HTMLها جهت رفع محدودیت ۱۰۰ مگابایتی گیتهاب و افزایش شدید سرعت بارگذاری (حجم کل سایت از ۱.۷ گیگابایت به ۱۷۰ مگابایت کاهش یافته است).

## نحوه راه‌اندازی روی GitHub Pages:

برای هاست کردن این محتوا روی GitHub Pages کافی است مراحل زیر را انجام دهید:

### روش اول: ایجاد ریپازیتوری جدید از پوشه `new`
1. ترمینال را در پوشه `new` باز کنید:
   ```bash
   cd new
   git init
   git add .
   git commit -m "Initial commit of Persian System Design course"
   ```
2. در گیت‌هاب یک ریپازیتوری عمومی (یا خصوصی با اکانت پرو) به نام دلخواه (مثلاً `system-design-fa`) بسازید.
3. کدها را به گیت‌هاب پوش (Push) کنید:
   ```bash
   git remote add origin https://github.com/<YOUR_USERNAME>/system-design-fa.git
   git branch -M main
   git push -u origin main
   ```
4. در صفحه ریپازیتوری گیت‌هاب، به مسیر زیر بروید:
   `Settings` > `Pages`
5. در بخش **Build and deployment**، گزینه **Source** را روی **Deploy from a branch** بگذارید و شاخه `main` و پوشه `/ (root)` را انتخاب کرده و دکمه **Save** را بزنید.
6. پس از ۱ تا ۲ دقیقه، آدرس وب‌سایت شما فعال خواهد شد:
   `https://<YOUR_USERNAME>.github.io/system-design-fa/`
